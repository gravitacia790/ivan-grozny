# Исповедь Ивана Грозного

Локальный образовательный сайт для совместного урока истории и информатики,
7 класс. Next.js, React, TypeScript, CSS, GSAP. Без регистрации учеников.

Посмотреть тестовую версию: https://gravitacia790.github.io/ivan-grozny/
Интерфейс опубликован из ветки `gh-pages`, сервер чата работает в Yandex Cloud
Functions: https://functions.yandexcloud.net/d4e15h0kkhld9p24dqgn .
Модель — Alice AI LLM через Yandex AI Studio; ключ хранится в Lockbox.
Полные исходники находятся в `main`, размещение описано в `docs/yandex-deployment.md`.
Агент ищет исторические публикации в интернете и показывает литературу только
по просьбе пользователя.

Текущее состояние и незавершённые материалы: `docs/site-state.md`.
Подготовка размещения в интернете: `docs/deployment.md`. В корне подготовлен
Dockerfile; production-сборка включает standalone-сервер, изображения, аудио и
материалы учителя. Проверки запускаются командами из инструкции.
Правила учебного агента: `docs/agent-rules.md`; исполняемая серверная версия —
`lib/instructions.ts`. Правила дальнейшей работы над проектом — `AGENTS.md`.

Авторизация с обновлённым ключом проверена 08.11.2026: OpenAI вернул HTTP 200.
Прежняя ошибка `401 invalid_api_key` относилась к старому ключу. Успешная
авторизация сама по себе не подтверждает полноценный живой диалог: его
нужно проверять отдельно; текущие живые пробы описаны в docs/verification.md.
Подробные результаты предыдущих проверок — в `docs/verification.md`.

## Запуск

Нужен Node.js 22.13 или новее и Python 3 для локального запуска с внешним RTF-файлом.

На этом Mac можно дважды щёлкнуть `Запустить сайт.command` в Finder:
он найдёт установленный Node.js 22, запустит сайт и покажет адрес.

```sh
npm ci
python3 scripts/with-local-key.py dev
```

Открыть http://127.0.0.1:3000. Скрипт читает существующий `../API.rtf` в память
процесса, не копирует ключ в проект и не выводит его. Этот внешний файл не
требуется добавлять в репозиторий. Если `OPENAI_API_KEY` уже задан в окружении,
скрипт использует его. Для стандартного серверного окружения:

```sh
npm run dev
npm run build
npm start
```

Настройки окружения перечислены в `.env.example`. Ключ задаётся только на
сервере как `OPENAI_API_KEY`; модель — `OPENAI_MODEL` (по умолчанию
`gpt-5-mini`); поиск — `OPENAI_RESEARCH_MODEL` (`gpt-5-mini`). Файлы `.env*` с секретами исключены из Git.
Доступ к API использует баланс проекта OpenAI; web_search оплачивается отдельно.

## Что подготовлено

- Первый экран, вступление с HTML video и аудиоверсией при отсутствии видео.
- Аудиоверсия: статичный кадр GPT Image 2.6, озвучка монолога OpenAI
  `gpt-4o-mini-tts`, голос `onyx`, около 42 секунд. Воспроизведение запускает
  пользователь; автоматического старта звука нет. Полный текст доступен рядом.
- Русские субтитры WebVTT, пропуск, управление звуком.
- Настоящий серверный запрос OpenAI Responses API; заготовленных ответов нет.
- Состояние ожидания, сохранение вопроса при ошибке, повтор отправки.
- 10 вопросов на беседу, до 1000 символов на вопрос; 6 запросов в минуту
  на сессию и 30 на процесс сервера; общий размер запроса до 24 КБ.
- Обязательный поиск по разрешённым сайтам и проверка ссылок минимум двух сайтов.
- Скрытая библиография, выдача источников предыдущего ответа по просьбе.
- До 38 секунд на поиск, до 17 секунд на стилизацию; сервер и клиент — 60 секунд.
- Беседа в localStorage, скачивание TXT и сброс с подтверждением.
- Адаптивный интерфейс, клавиатурное управление, фокус, уменьшение движения.

## До школьного использования

Подборка источников учителя пока не предоставлена. Заполнить
`content/teacher-materials.md`, проверить её, затем установить на сервере
`TEACHER_MATERIALS_APPROVED=true`. Несогласованная подборка не используется как фактическая основа.
Исторические ответы разрешены по найденным публикациям и не ограничены
прежним корпусом четырёх извлечений. При нехватке свидетельств агент сообщает об этом.
Роль и правила находятся в `lib/instructions.ts`.

Полноценное видео с движением губ пока отсутствует. При его отсутствии
показывается аудиоверсия: `public/media/ivan-gpt-image-2.6-v1.png` как статичный
кадр и `public/media/intro-voice-v1.mp3` как синтетическая озвучка. Эти материалы
не выдаются за готовую анимацию или синхронизацию губ. На главной странице
пока сохранён предоставленный художественный портрет. Готовый ролик разместить
в `public/media/intro.mp4`, синхронизировать `intro.ru.vtt`. Монолог в
`content/intro.ts` нужно согласовать с учителем. Концепция, раскадровка и
перечень материалов — в `docs/concept.md`. Для озвучивания используется отдельный
Text-to-Speech API, как описано в официальном руководстве:
https://developers.openai.com/api/docs/guides/audio

Для шрифтов используется Google Fonts; при отсутствии интернета работают
системные шрифты. Сам чат требует связи сервера с OpenAI. Текст вопросов и
история текущей беседы отправляются OpenAI; `store:false` отключает сохранение
Response как доступного через API объекта. Это не обещание нулевого хранения
данных у провайдера. Приложение не ведёт журналов текста и не сохраняет
диалоги на сервере.

## GitHub и размещение

Загружать на GitHub **только папку `ivan-grozny`**. В родительской папке лежат
личные материалы и файл API. Не добавлять их в репозиторий.

Сайт не является статическим: для `/api/chat` нужен Node.js-сервер.
GitHub хранит исходники; GitHub Pages не запускает серверный обработчик чата.
Для доступного в интернете сайта потребуется отдельный сервер с настройками
окружения. Публикация в этой задаче не выполнялась.

Лимит частоты рассчитан на один локальный процесс (весь класс может работать
с одним сервером). Для нескольких экземпляров на хостинге нужен общий
rate-limit store; клиентский ID сессии не является аутентификацией.
Локальный сервер слушает только 127.0.0.1. Доступ с других школьных ПК требует
осознанной настройки адреса прослушивания и школьной сети.

## Проверки

```sh
npm run typecheck
npm run test:api
npm run build
```

API: `GET /api/chat` возвращает только статус наличия ключа и согласования
материалов; `POST /api/chat` принимает массив реплик user/assistant и session.
Ошибки провайдера не передаются в браузер в исходном виде.

Документация: https://developers.openai.com/api/docs/guides/text
