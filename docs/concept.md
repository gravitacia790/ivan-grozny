# «Исповедь Ивана Грозного»: концепция и производство

Для совместного урока истории и информатики, 7 класс.

## Композиция

Первый экран: слева крупное название, краткое приглашение и кнопка входа,
справа портрет в тонкой орнаментальной раме. Ссылка на вопросы доступна сразу.
Внизу три действия ученика: войти в эпоху, задать вопрос, проверить ответ.
Палитра: тёмное дерево, угольный, пергамент, приглушённое золото и бордовый.
Орнамент и шрифты относятся к оформлению интерфейса, а не к исторической сцене.

Экран разговора: слева портрет с именем, справа светлая область переписки.
Под ней поле вопроса, отправка, скачивание и сброс с подтверждением.
На телефоне портрет превращается в узкую полосу, приоритет получает переписка.
Ответы помечаются как ИИ-реконструкция. Регистрация не нужна.

## Раскадровка, 40 секунд

| Время | Кадр и действие | Звук |
| --- | --- | --- |
| 0–6 с | Общий план московских палат XVI века. Иван у стола с документами. Свет окна и свечей. | Начало монолога, спокойный мужской голос. |
| 6–13 с | Медленный наезд. Руки неподвижны, взгляд направлен на документы. | Судебник, стрелецкие части, расширение государства. |
| 13–21 с | Средний план. Иван поднимает голову, замечает зрителя. | Власть, опричнина, цена войны. |
| 21–28 с | Сдержанный взгляд в камеру. Лицо хорошо освещено. | Спор о причинах и последствиях решений. |
| 28–40 с | Приглашение к разговору. Небольшая естественная пауза. | Финальные слова монолога. |

Монолог в `content/intro.ts` содержит около 70 слов. Он является литературной
реконструкцией и ожидает согласования учителем истории. Субтитры подготовлены
в `public/media/intro.ru.vtt`, тайминг нужно уточнить после монтажа.

## Материалы и их статус

| Материал | Статус |
| --- | --- |
| Предоставленный художественный портрет | Временный материал: `public/media/ivan-reference.png`; перед публикацией уточнить право использования. |
| Фотореалистичный постер: Иван за столом в палатах | Создан через GPT Image 2.6: `public/media/ivan-gpt-image-2.6-v1.png`; показан в аудиоверсии как статичный ИИ-кадр. Ожидает согласования. |
| Видео MP4/WebM, 30–45 секунд | Отсутствует. Разместить готовый MP4 как `public/media/intro.mp4`. |
| Мужской голос | Озвучка монолога создана через OpenAI `gpt-4o-mini-tts`, голос `onyx`: `public/media/intro-voice-v1.mp3`, около 42 секунд. Синтетический голос, воспроизведение по действию пользователя. |
| Синхронизация губ | Пока отсутствует. Аудиоверсия со статичным постером не считается готовым видео. |
| Русские субтитры | Черновик готов; требуется синхронизация с итоговым видео. |
| Согласованные источники учителя | Отсутствуют. Добавить в `content/teacher-materials.md`. |

Изображение Москвы из задания служит ориентиром фактур и атмосферы. Его
не следует использовать как документальную реконструкцию XVI века:
историческую уместность каждой архитектурной детали нужно проверить отдельно.

## План реализации и дальнейшего наполнения

1. Локальный Next.js + React + TypeScript, оформление CSS, переходы GSAP.
2. Вход, проигрыватель с субтитрами и независимый текстовый чат.
3. Серверный Responses API: роль, ограничения, контекст учителя, тайм-аут и лимиты.
4. Хранение беседы в браузере, скачивание текста, доступность и мобильная версия.
5. Проверка сборки, интерфейса, успешного ответа и ошибок сервиса.
6. После согласования: добавить источники учителя, фотореалистичный постер и
   готовое видео; сверить монолог и субтитры, провести пробный урок.

Сайт создаётся локально по прямому запросу пользователя. Подготовлены
изображение GPT Image 2.6 и озвучка монолога через API. Генерация полноценного
видео с движением губ и публикация сайта пока не выполнялись.
