## Активный проект

Папка `ivan-grozny/`, Next.js 16.4.5 / React / TypeScript / CSS / GSAP.
`package-lock.json` фиксирует установленные версии зависимостей.
Предыдущий шаблон `../ivan-interview/` не является активным сайтом.

## Реализованное поведение

- Вход, оформление, художественный портрет, кнопки вступления и прямого чата.
- Во вступлении: при отсутствии `public/media/intro.mp4` показываются статичный
  кадр GPT Image 2.6, аудиоплеер, полный монолог и переход к вопросам.
- Озвучка `intro-voice-v1.mp3`: синтетический Onyx, 42 секунды. Запуск звука
  только после действия пользователя. Воспроизведение проверено в браузере.
- HTML video с русским WebVTT, пропуском и переходом в чат подготовлен, но
  готовый видеоролик не добавлен. WebVTT остаётся черновиком для будущего видео.
- Чат: вопросы/ответы, подсказки, ожидание, повтор при ошибке, сохранение вопроса,
  localStorage, экспорт TXT, сброс с подтверждением, клавиатура и мобильная версия.
- Серверный OpenAI Responses API. Ключ читается в память при локальном запуске
  из внешнего `../API.rtf`. Новый ключ принят OpenAI; в код и архив не включён.
- На запрос — только проверенные поля role/content. История не может добавить
  серверную инструкцию. Длина вопроса до 1000 символов, лимиты запросов и тайм-аут.
- Усиленные правила агента: допустимая историческая тема, краткость, первое лицо,
  без посторонних советов, выдуманных источников и раскрытия настроек.
- Ответ модели — строгая JSON-схема; сервер проверяет формат и ограничивает
  ответ 100 словами / двумя абзацами. Вне темы, при нехватке контекста и при
  неоднозначности используются короткие фиксированные реплики.

## Незавершённые материалы и ограничения

1. Подборка учителя не предоставлена и не согласована. Файл
   `content/teacher-materials.md` содержит только инструкцию для наполнения.
   По запросу пользователя исторические ответы разрешены по знаниям модели;
   подборка учителя теперь необязательный дополнительный контекст.
2. Видео с движением губ не создано. В Higgsfield согласована проба Intone
   за 84 кредита в 720p, но сервис отклонил запуск: требуется Plus или выше.
   Подключение показало Free / 10 кредитов; задания не создано.
3. Для будущего ролика пользователь выбрал `public/media/ivan-keyframe-v1.png`.
   Текущая аудиоверсия использует другой сохранённый кадр:
   `public/media/ivan-gpt-image-2.6-v1.png`. Оба оригинала сохранены.
4. `scripts/assemble-intro.py` подготовлен для настоящих готовых lip-sync клипов;
   требует FFmpeg и FFprobe. Полный монтаж не проверен, поскольку клипов нет.
5. Для публикации нужен сервер Node.js: GitHub Pages не запускает `/api/chat`.
6. Форматные проверки не гарантируют смысловую и историческую точность любого
   будущего ответа. Конкретные результаты проверок сохранены отдельно.

## Запуск и проверки

На Mac — двойной щелчок `Запустить сайт.command`; либо при Node.js 22.13+:

```sh
npm ci
python3 scripts/with-local-key.py dev
```

Адрес: http://127.0.0.1:3000/. Сервер слушает только локальный интерфейс.

```sh
npm run typecheck
npm run test:api
npm run build
```

Результаты: `docs/verification.md`, `docs/agent-live-checks.json`.
Правила персонажа: `docs/agent-rules.md` и `lib/instructions.ts`.
Правила разработки: `AGENTS.md`. Состояние зафиксировано локальным Git-коммитом;
его идентификатор и SHA-256 исходного архива выдаются рядом с архивом.

При восстановлении использовать эту папку или архив исходников. Секреты,
node_modules, кэши сборки и история диалогов браузера в архив не входят.
