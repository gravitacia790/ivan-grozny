## Фиксация правил учебного агента

- `lib/instructions.ts`: границы темы, краткость, источники, устойчивость роли.
- Responses API использует строгую JSON-схему; сервер выбирает фиксированную
  реплику для постороннего запроса, нехватки материалов или неясного вопроса.
- Проверяются длина (100 слов / 2000 символов), максимум два абзаца,
  отсутствие кода, ссылок, Markdown и эмодзи. Непрошедший ответ не показывается.
- В провайдер передаются только role/content; дополнительные клиентские поля
  отбрасываются. Серверная инструкция заново добавляется при каждом запросе.
- Три настоящих запроса на работающем сайте с новым ключом прошли:
  рецепт пиццы — отказ по теме; подмена роли/раскрытие промпта — отказ по теме;
  вопрос о Судебнике без согласованных источников — нехватка материалов.
  Тексты запросов и фактических ответов: `agent-live-checks.json`.
- Изолированные API-тесты покрывают фиксированные реплики, неподтверждённые
  материалы, нарушение длины/абзацев/формата, JSON, лишние клиентские поля,
  неверную роль и прежние проверки ошибок/лимитов.
- Эти результаты не являются доказательством полной семантической защиты
  от всех возможных атак или исторической достоверности будущих ответов.

## Первоначальная проверка

- `npm run build` — успешно, включая проверку TypeScript.
- `npm run typecheck` — успешно.
- `npm run test:api` — успешно. Изолированные проверки без сети:
  ограничения сообщений, запрет пользовательской system-роли, проверка Origin,
  извлечение текстового ответа, лимит частоты, отсутствующий ключ,
  ошибки авторизации, баланса, тайм-аут и незавершённый ответ.
- Браузер: главная страница, переход во вступление, текстовая версия при
  отсутствующем MP4, переход к вопросам, выбор вопроса, отправка Enter,
  состояние ожидания, сохранение вопроса при ошибке, отмена и подтверждение
  сброса. На ширине 390 и 1280 px горизонтального переполнения нет.
- Настоящий запрос к OpenAI с ключом из внешнего файла `API.rtf`:
  HTTP 401, `invalid_api_key`. Успешный живой ответ не подтверждён.
  Проверка обработчика на успешном ответе использует явно подменённый сетевой
  ответ в изолированном тесте и не считается живым подключением.

Ограничения: ручной экспорт и восстановление успешной реальной беседы пока не
проверены из-за недействующего ключа. Видео, фотореалистичный постер и
согласованные исторические источники отсутствуют; их статус описан в концепции.

Перед уроком требуется действующий ключ, согласованные материалы учителя,
проверка ответов по источникам и пробный запуск на школьном оборудовании.
