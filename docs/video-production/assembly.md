# Сборка готовых видеофрагментов

`scripts/assemble-intro.py` собирает **реальные видеофрагменты с уже готовым
движением губ**. Скрипт не создаёт lip-sync, не оживляет статичные картинки
и не обещает синхронизацию при замене звука. Замена голоса допустима только
после отдельной подготовки совпадающего движения губ.

На проверенном Mac пока не найдены FFmpeg и FFprobe; Python-библиотеки
imageio_ffmpeg, moviepy и av также отсутствуют. Для монтажа потребуется
установка FFmpeg. Скрипт использует только стандартную библиотеку Python 3.

Из папки проекта:

```sh
python3 scripts/assemble-intro.py \
  --clip work/shot-01.mp4 --clip work/shot-02.mp4 \
  --clip work/shot-03.mp4 --clip work/shot-04.mp4 \
  --vtt work/final.ru.vtt --check-only
```

Когда проверка пройдёт, убрать `--check-only` для создания
`public/media/intro.mp4`. При отдельной готовой озвучке добавить
`--audio work/voice.wav`. Скрипт откажется растягивать голос или зацикливать
персонажа: длительности должны уже совпадать с допуском 0,25 секунды.

Для короткой пробы добавить `--pilot --output work/pilot-preview.mp4`.
Для полного вступления проверяется общая длительность 30–45 секунд.
Ролик нормализуется в 1920×1080, 30 кадров/с, H.264 и AAC; в MP4 добавляется
отключаемая русская дорожка субтитров. Исходный WebVTT нужно отдельно
сохранить как `public/media/intro.ru.vtt`, поскольку сайт использует HTML track.
Готовые файлы не перезаписываются.

Скрипт проверяет наличие потоков, длительности, временные метки субтитров
и параметры готового MP4. Он не может автоматически подтвердить дикцию,
историческую корректность, совпадение лица и движение губ — это отдельная
проверка всего ролика человеком. Реальное кодирование пока не проверено:
исходных видеофрагментов и FFmpeg в среде нет.
