# Созданные материалы

8 ноября 2026 года новый ключ из внешнего `API.rtf` принят OpenAI:
запрос списка моделей вернул HTTP 200. Ключ не копировался в исходники,
командную строку или публичные файлы. Локальный запуск читает его из прежнего
файла автоматически. Ранее записанная ошибка 401 относится к старому ключу.

## Изображение GPT Image 2.6

- Файл: `public/media/ivan-gpt-image-2.6-v1.png`.
- Фактически вызванная модель: `gpt-image-2.6-sunburst`.
- Параметры: medium, 1536×1024, один результат.
- Получено через OpenAI Images API штатным инструментом imagegen.
- Изображение осмотрено: один персонаж, лицо хорошо читается, бумага,
  свечи и интерьер присутствуют. Историческая точность и сходство требуют
  согласования учителем; это художественная реконструкция.
- Формат кадра 3:2, не готовый видеокадр 1920×1080. Для финального видео
  потребуется согласованное кадрирование или подготовка широкого кадра.

## Озвучка

- Файл: `public/media/intro-voice-v1.mp3`.
- Фактически вызванная модель: `gpt-4o-mini-tts`, голос `onyx`.
- HTTP 200; получен MP3 размером 672000 байт.
- `afinfo`: 42 секунды, mono 24 kHz, 128 kbit/s.
- В запросе использован полный монолог из `content/intro.ts`.
- Голос синтетический, не подлинный голос Ивана IV и не клонированный голос.
- Параметры запроса без секретов сохранены в `speech-request.json`.

Указанная пользователем документация
https://developers.openai.com/api/docs/guides/audio рекомендует отдельный
text-to-speech workflow для narration/generated speech; применён соответствующий
Speech API. Запись можно прослушать в аудиоплеере. Прослушивание и проверка
дословной дикции учителем остаются этапом приёмки; одни метаданные не доказывают
качество произношения и интонации.

## Что ещё не создано

Видео с движением персонажа и синхронизацией губ не создавалось. GPT Image 2.6
не поддерживает аудио/видео. Озвучка и статичное изображение не выдаются за
полноценный lip-sync ролик. Для него потребуется отдельная видеомодель.
Ранее оценён один пробный текстовый ролик Seedance 2.0 на 10 секунд за
120 кредитов Higgsfield; эта генерация не запускалась, нового согласия на
расход кредитов не получено. Он не гарантирует использование данной озвучки
и данного кадра — для таких входов нужно подготовить отдельный запрос.

Документация модели:
https://developers.openai.com/api/docs/models/gpt-image-2.6-sunburst
